<h1>Counselling System – Frontend</h1>

<h2>📝 Overview</h2>
<p>
This is the frontend for the counselling system website, built to work alongside the backend and provide a responsive user interface.
</p>

<h2>🎯 Features</h2>
<ul>
  <li>User facing UI for scheduling, sessions and dashboard</li>
  <li>Seamless integration with the backend APIs</li>
  <li>Responsive design (desktop + mobile)</li>
  <li>Built with modern frontend tools and frameworks</li>
</ul>

<h2>🚀 Getting Started</h2>

<h3>Prerequisites</h3>
<ul>
  <li>Node.js & npm/yarn</li>
  <li>Access to the backend API (see backend repo)</li>
</ul>

<h3>Setup Steps</h3>
<pre>
git clone https://github.com/munikumar2003/counselling-system-frontend.git
cd counselling-system-frontend
</pre>

<h4>Install dependencies</h4>
<pre>
npm install
# or
yarn install
</pre>

<h4>Run in development mode</h4>
<pre>
npm run dev
# or
yarn dev
</pre>

<p>Open <code>http://localhost:5173</code> (or the port Vite indicates) in your browser.</p>

<h4>Build for production</h4>
<pre>
npm run build
# or
yarn build
</pre>
